# Qavyo Website Copy

Edit `site-copy.json` to change public website copy without opening the large
saved HTML files.

- `navigation.roadmapPages` keeps a page built but removes it from menus.
- `navigation.removedPages` prevents legacy links from appearing.
- `pages` holds the title and intro for every retained page.
- `homepage` controls the homepage hero, questions, and closing call to action.

Use plain text. The page layout and existing image assets are intentionally not
managed here.
